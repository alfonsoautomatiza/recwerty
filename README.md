# RecWERTY v3.2

![Version](https://img.shields.io/badge/version-3.2-blue)
![Platform](https://img.shields.io/badge/platform-Windows-blue)
![Python](https://img.shields.io/badge/python-3.13-blue)

**RecWERTY** is a professional screen recording tool for Windows with motion effects, audio enhancement, and branding.

## Key Features

- **Screen recording** — Full screen, windows, or custom regions
- **Visual effects** — Click ripples, cursor trail, particles, transitions
- **Keyboard sounds** — Polyphonic sounds with key-type variation
- **Voice enhancement** — Studio-grade filters: noise reduction, compression, equalization
- **Branding** — Animated intros with logo, colors, and typography
- **Social presets** — Optimized exports for YouTube, TikTok, Instagram, Twitter/X, LinkedIn, WhatsApp
- **GIF export** — Optimized animated GIFs with quality presets
- **Render queue** — Parallel processing with up to 2 simultaneous jobs

## Quick Install

```bash
git clone <repo-url>
cd recwerty
uv sync
uv run python generate_assets.py
uv run python main.py
```
