# Atajos de teclado

| Atajo | Acción |
|---|---|
| **Alt + R** | Detener grabación |
| **Alt + Z** | Activar/desactivar zoom manual |
| **ESC** | Cancelar selección de zona |
| **Ctrl + Shift + R** | Iniciar captura rápida (atajo global) |

Los atajos se muestran en la interfaz durante la grabación.
