# Microsoft Store

RecWERTY usa Microsoft Store como canal público de instalación y actualización cuando la publicación esté disponible.

| Dato | Valor |
|---|---|
| Producto | RecWERTY |
| Versión | 3.2.4 |
| Store ID | `9NLD6GX4L1R1` |
| Vínculo de Microsoft Store | Disponible después de publicar en Microsoft Store. |
| Deep link de Windows | Disponible después de publicar en Microsoft Store. |

!!! info "Disponibilidad"
    El Store ID ya está reservado. El vínculo público y el deep link se completan después de publicar la app en Microsoft Store.

## Actualizaciones

Las versiones para usuarios finales se publican por Microsoft Store / Partner Center. RecWERTY no incluye un actualizador propio dentro de la aplicación.
